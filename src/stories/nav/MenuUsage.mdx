# Basic usage example for Nav Menu

```html
<pi-nav-menu
.items=${menuData}
?vertical=${vertical}
></pi-nav-menu>
```

# Props

## Items
This should be a JSON or Javascript array of menu items. See the JSON example for Nav Menu for reference.

## Vertical
This attribute should only be added if you want a vertical menu. Otherwise, omit this attribute entirely.
